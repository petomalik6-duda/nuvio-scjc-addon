# SCJC Nuvio Bridge 1.1.0

Nuvio/Stremio-compatible addon reconstructed from the supplied Android APK. The goal of v1.1.0 is to follow the APK's observable login, session, token and playback flow closely instead of repeatedly creating fresh sessions/tokens.

It requires the user's own valid KRA / Stream Cinema account. It does not bypass login, subscription checks or DRM.

See the deployed `/configure` page for install setup and `/health` for service status.
